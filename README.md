# خاورمیانه‌شناس

بازی آموزشی تعاملی دربارهٔ ۱۷ کشور خاورمیانه، در قالب یک صفحهٔ وب تک‌فایلی (`index.html`) با رابط فارسی و راست‌به‌چپ.

- **حالت یادگیری:** نقشهٔ تعاملی (بزرگ‌نمایی با دو انگشت) + کارت هر کشور: پرچم، پایتخت، زبان رسمی، نکته‌ها
- **کوییزها:** پرچم، پایتخت، نقشه، زبان، نکته‌ها و کوییز ترکیبی — ۱۰، ۲۰ یا همهٔ سؤال‌ها
- امتیاز با جایزهٔ پشت‌سرهم، مرور و تمرین دوبارهٔ اشتباه‌ها، ذخیرهٔ بهترین امتیاز، حالت تیره

فقط `index.html` را در مرورگر باز کنید.

## ساخت دوباره
`index.html` از `src/template.html` و داده‌های مرزی Natural Earth (بستهٔ `world-atlas`) ساخته می‌شود:

```
cd tools && npm install && node build.mjs
```
