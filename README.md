# Countryball Explorer — کاوشگر کانتری‌بال

بازی آموزشی تعاملی دربارهٔ کشورهای **آسیا** و **اروپا (۴۴ کشور)**. آسیا پنج بخش دارد: **خاورمیانه (۱۷)**، **آسیای شرقی (۶)**، **آسیای جنوب شرقی (۱۱)**، **آسیای جنوبی (۸)** و **آسیای مرکزی و قفقاز (۸)**. هر بخش همهٔ ویژگی‌های زیر را دارد. گزینهٔ **«کوییز همهٔ کشورها»** در صفحهٔ اول هم همهٔ ۹۴ کشور را در همهٔ کوییزها با هم می‌آورد (سؤال‌های نقشه روی نقشهٔ منطقهٔ همان کشور).
زبان پیش‌فرض **انگلیسی** (MidEast Explorer) است و با دکمهٔ «فا / EN» بالای صفحه کل برنامه، از جمله اطلاعات کشورها، به فارسی (راست‌به‌چپ) و برعکس عوض می‌شود.

- **حالت یادگیری:** نقشهٔ تعاملی (بزرگ‌نمایی با دو انگشت) + کارت هر کشور: پرچم، پایتخت، زبان رسمی، نکته‌ها
- **کوییزها:** پرچم، پایتخت، نقشه، زبان، نکته‌ها و کوییز ترکیبی — ۱۰، ۲۰ یا همهٔ سؤال‌ها
- **کوییز ترکیب پرچم‌ها:** این پرچم ترکیبی از کدام دو کشور است؟
- **دوستی پرچم‌ها:** دو کشور را کنار هم بگذار؛ پرچم ترکیبی (۴ مدل)، اسم دوستی، درصد دوستی، مرز/زبان/دریای مشترک و فاصلهٔ پایتخت‌ها
- **کلمه‌های ساده:** هر کانتری‌بال ۱۰ کلمه به زبان خودش (فارسی، عربی با لهجهٔ محلی، کردی سورانی، ترکی، عبری، یونانی) با نوشته، تلفظ فارسی و صدا یاد می‌دهد (فایل‌های صوتی داخل `audio/` که با `tools/make_audio.py` و espeak-ng ساخته شده‌اند و آفلاین کار می‌کنند؛ صدای طبیعی گوشی هم از تنظیمات قابل انتخاب است)؛ با تمرین «گوش بده و پیدا کن»
- دکمهٔ برگشت گوشی: برگه‌ها را می‌بندد و به صفحهٔ قبل برمی‌گردد (وسط کوییز اول می‌پرسد)
- **کانتری‌بال** متحرک هر کشور با کلاه سنتی‌اش (پلک می‌زند، می‌خندد، ناراحت می‌شود و با زدن رویش سلام می‌کند)
- **افکت‌ها:** کانفتی، جرقه، آتش‌بازی و انیمیشن‌ها؛ **صدا** (ساخته‌شده با Web Audio) و موسیقی پس‌زمینهٔ اختیاری
- **جشن‌ها به‌طور خودکار بر اساس تاریخ:** نوروز، سیزده‌به‌در، چهارشنبه‌سوری، یلدا، مهرگان، هالووین، کریسمس، سال نو میلادی، ولنتاین، رمضان، عید فطر و قربان (با تقویم شمسی و قمری مرورگر). پیش‌نمایش همه از ⚙️ تنظیمات
- پرچم ایران: پرچم شیر و خورشید دوران پهلوی
- امتیاز با جایزهٔ پشت‌سرهم، مرور و تمرین دوبارهٔ اشتباه‌ها، ذخیرهٔ بهترین امتیاز، حالت تیره

فقط `index.html` را در مرورگر باز کنید.

## نصب روی گوشی (مثل یک برنامه)
بازی یک PWA است: بعد از انتشار روی GitHub Pages، آیکون روی صفحهٔ اصلی گوشی می‌گیرد، تمام‌صفحه باز می‌شود و آفلاین هم کار می‌کند.

1. در GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**، شاخهٔ اصلی و پوشهٔ `/ (root)` را انتخاب و Save کنید.
2. نشانی `https://grandddlc-tech.github.io/Middle-east/` را در گوشی باز کنید.
3. **اندروید (Chrome):** دکمهٔ «نصب» داخل بازی، یا منوی ⋮ ← Install app.
   **آیفون (Safari):** دکمهٔ اشتراک‌گذاری ← Add to Home Screen.

با هر تغییر در فایل‌ها، مقدار `VERSION` در `sw.js` را بالا ببرید تا گوشی‌ها نسخهٔ تازه را بگیرند.

## ساخت دوباره
`index.html` از `src/template.html`، داده‌های اروپا و آسیا (`src/europe.js`، `src/asia.js` و کلمه‌های ساخته‌شده در `src/*_words.js`) و داده‌های مرزی Natural Earth (بستهٔ `world-atlas`) ساخته می‌شود. کریمه طبق مرز شناخته‌شدهٔ بین‌المللی جزو اوکراین کشیده می‌شود.

```
cd tools && npm install && node build.mjs
node icons.cjs   # ساخت دوبارهٔ آیکون‌ها (اختیاری)
```

فونت: [Vazirmatn](https://github.com/rastikerdar/vazirmatn) (مجوز OFL، در پوشهٔ `fonts/`).

## نسخهٔ اندروید (APK)
با هر push، گردش‌کار `.github/workflows/android.yml` بازی را با Capacitor به یک اپ اندروید تبدیل می‌کند و در Releases منتشر می‌کند.
لینک دانلود آخرین نسخه:
https://github.com/grandddlc-tech/Middle-east/releases/latest/download/Countryballs.apk

پروژهٔ اندروید در `native/` است (آیکون و صفحهٔ شروع در `native/assets/`، ساخته‌شده با `tools/icons.cjs`).
هر نسخه باید با یک کلید ثابت امضا شود تا روی نسخهٔ قبلی نصب شود. اگر در Secrets مخزن `ANDROID_KEYSTORE_BASE64` و `ANDROID_KEYSTORE_PASSWORD` تعریف شده باشد از آن استفاده می‌شود؛ وگرنه کلید در اولین ساخت تولید و در کش خصوصی GitHub Actions نگه داشته می‌شود (کلید هیچ‌وقت در مخزن عمومی قرار نمی‌گیرد).
